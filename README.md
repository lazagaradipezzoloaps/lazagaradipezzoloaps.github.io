# La Zagara di Pezzolo Radici e Futuro APS – sito web

Sito dell'associazione di promozione sociale La Zagara di Pezzolo (Pezzolo, Messina).
Pubblicato con GitHub Pages: https://lazagaradipezzoloaps.github.io

- I testi si modificano in `sorgente/pagine/`, gli eventi in `contenuti/eventi.json`.
- Per ricostruire il sito: `npm install` e poi `npm run build`.
- Istruzioni complete in `CLAUDE.md`.

Animazioni realizzate con [GSAP](https://gsap.com), [Lenis](https://lenis.darkroom.engineering)
e [React Bits](https://reactbits.dev). Licenze in `assets/js/LICENZE-terze-parti.txt`.
